おすすめのサウナ

  • 京都 : ルーマプラザ (ホームサウナ。京都に来たらとりあえずここに行け。)
  • 大阪 : ニュージャパン梅田、大東洋 (二大巨頭。個人的にはニュージャパン派。)
  • 神戸 : 神戸サウナ&スパ (フィンランドサウナと30分おきのアウフグースで無限ループ。11.7℃の水風呂もありがたい。)
  • 奈良 : 奈良健康ランド (有料サウナエリアが最高。アクセス以外は完璧。)
  • 滋賀 : あがりゃんせ (琵琶湖を眺めながらの外気浴が最高。)
  • 東京 : かるまる池袋店 (4種のサウナと3種の水風呂が全部最高。泊まれる個室もあるのもありがたい。)
  • 愛知 : ウェルビー今池店、栄店 (質のいいサウナと水風呂。泊まれる半個室もある。個人的には宿泊前提なら今池派。)
  • 福岡 : ウェルビー福岡店 (同じく良質なサウナと水風呂。博多駅近くにあり、泊まれる半個室もある。)
  • 熊本 : 湯らっくす (最高のフィンランドサウナ、アウフグース、水風呂。個人的な理想のサウナ。)
  • 茨城 : アーバンホテルつくば (ビジネスホテルなのにサウナと外気浴のレベルが高すぎる。)
  • 神奈川 : スカイスパ横浜 (ビル14階にあるサウナ室からの眺めが良い。しかしいつも混んでる。)
  • 静岡 : サウナしきじ (東のサウナの聖地。いいサウナだが、ゆえにいつも混んでる。)
  • 千葉 : スパメッツァおおたか (激熱のオートロウリュと冷たい水風呂、広い外気浴スペースが最高。)
  • 宮城 : スパメッツァ仙台 (熱いオートロウリュとフィンランドサウナ、冷たい水風呂が最高。)
  • 新潟 : じょんのび館 (広くてセルフロウリュできるサウナ室と冷たい水風呂、自然の中での外気浴が最高。)
  • 岡山 : ドーミーイン岡山 (セルフロウリュできるフィンランドサウナと冷たい水風呂。ビジネスホテルのレベルを超えている。)
  • 埼玉 : おふろの王様和光店 (理化学研究所近くの貴重なサウナ兼スーパー銭湯。ちゃんとしたサウナと水風呂、広い露天スペースが良い。)
